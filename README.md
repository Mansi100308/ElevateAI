# ElevateAI

ElevateAI is an AI-powered career and study assistant designed to help students with learning, planning, and career guidance.

## Features

- 🤖 Ask AI Assistant
- 🎯 Career Mentor
- 📚 Study Planner
- 🏠 Student-friendly dashboard

## Technologies Used

### Frontend
- React.js
- Vite
- CSS

### Backend
- Python

## Project Structure

```text
ElevateAI/
│
├── backend/
│   └── main.py
│
├── frontend/
│   ├── src/
│   ├── package.json
│   └── vite.config.js
│
└── README.md
```

## How to Run the Project

### Backend

```bash
cd backend
python main.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
